New in this build:

- Your equipment list on the sheet: with a custom list chosen in Settings → Equipment, house weapons now appear in the Weapons section (to-hit, damage, ranges), and house armour and shields count for AC and movement. Class warnings use each house item's usableBy.
- Item notes: an empty Notes box in Equipment shows what the item is in grey, such as "AC 8 [11], light" or "melee, slow, two-handed". Press Return in Notes to keep it in the file.
- Class warnings read the same in the shop and on the sheet, and name the item: "Clerics normally use blunt weapons only, not a sword."
- A class typed in lower case ("thief", "dwarf") gets its thief skills, construction tricks and spells, like "Thief".
- A file set to rules the app doesn't have yet (variant: advanced) says so in the rules notes, and uses Classic Fantasy where the rules match.

Things to try:
- Make a list with Settings → Equipment → New List… (the starting file has an example of each section, ready to uncomment), add a house weapon and some house armour, buy them, and check the sheet. Is anything unclear about what a house item does?
- Look through a character's Equipment. Do the grey notes help, or get in the way?
- Use Edit → Undo and Redo freely, especially in boxes you've just typed in. Tell us if a value flips back and forth.
